## 恢复的方法行为，不与程序缺陷混为一谈

1. 因子采纳默认恢复仓库原有 LLM 判断，不再由本地 IC-first 门槛隐式覆盖。IC 明显下降但 LLM 返回 yes 的测试，默认保持 LLM 决策。此举是恢复方法，不意味着统计上更稳健。
2. 原 IC 规则仍可显式选择：QLIB_FACTOR_ACCEPTANCE_POLICY=ic。测试确认启用后能拒绝 IC 不达标的候选，并在反馈注明规则覆盖。
3. 撤除本地“全程只许确定性公式”的限制，恢复仓库原有逐步探索复杂/机器学习因子的范围。未改变用户的实际超时配置、执行环境或自动启动时长。
4. 没有混入 FactorMiner 的新相关阈值、家族禁区或新搜索算法。
